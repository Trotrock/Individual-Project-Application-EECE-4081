# Individual-Project-Application-EECE-4081-
This repository is the main location for the Software Engineering individual app project that shows my task manager application and its various iterations.

  In today's modern world filled with various electronics such as phones, computers, smart watches, etc. It has become a common habit for people to constantly look at a screen. The average person spends about 4 hours daily looking at their phones. This, paired with also looking at any other electronic screen ca led to over half of the day being used exclusively on just screen viewing. This can cause issues as people have tasks throughout the day which can either require immediate attention, or not which in turn causes forgetfulness when one has been looking at their devices, to mitigate this, a good way to take advantage of the screen usage time is to develop an application that allows users to input a task and set a date reminder. Once this task has been added, the app will keep track of the time the user input and once the timer has reached the deadline, it sends out a notification to the user reminding them that a task is due.

- The application will make use of the python programming language alongside the Django framework for my application
