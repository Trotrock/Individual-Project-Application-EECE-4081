# Individual-Project-Application-EECE-4081-
This repository is the main location for the Software Engineering individual app project that shows my task manager application and its various iterations.

  Across the entire globe, there are millions of people who watch various forms of sports; from American Football, hockey, and basketball, but one of the biggest sports today is Football. People engage with this sport as it allows us to form connections with those who share a following for one specific football club/national team. With the constant bustle of daily life however, it can be extremely difficult to keep up with any form of news updates and on occasion, forget when their team plays. A solution to this problem is a tracker that allows the user to get a live matchday countdown timer, where the team currently sits in their respective league tables, and the current formation with active or injured players. This app will focus on the updates for one specific football club, FC Barcelona.
  

- The application will make use of the python programming language alongside the Django framework for my application
- Work will take place within the VScode IDE for visual clarity and ease of use for commits and updates
